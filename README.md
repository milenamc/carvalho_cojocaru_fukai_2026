# Carvalho, Cojocaru and Fukai (2026)

This repository includes the scripts and notebooks required to reproduce the results of "Cross-layer non-random networks associated with reward-earning motor behavior" (provisional title, under preparation). The graph-based analysis is run with the help of a local library, `graphcheck`. This analysis uses the output of the analysis run using [`spykesim-lite`](https://github.com/oist-ncbc/spykesim-lite).

## Requirements

This library was tested on Python 3.12.9 and 3.12.10 (Mac). The analysis reported in the manuscript used the 3.12.9 environment. The following libraries are required in the local environment (in parentheses: versions used when running on Python 3.12.10):

- `numpy` (2.3.5)
- `pandas` (3.0.6)
- `scipy` (1.18.1)
- `networkx` (3.7)
- `matplotlib` (3.11.2)
- `seaborn` (0.13.2)
- `statannotations` (0.7.2)
- `statsmodels` (0.15.0)

## How to run

### Data preparation

The current code is tailored to process the cross-layer rat motor cortex dataset previously described in [Isomura et al. (2009)](https://www.nature.com/articles/nn.2431), published as [**10.5281/zenodo.22055254**](https://zenodo.org/records/22055254). Each session contains `All.clu.X` and `All.res.X` files, with X = 1, 2 indicating the index of the tetrode (1: L2/3, also referred to as "superficial layer"; 2: L5, or "deep layer").

Additionally, this library takes as input the results of [`spykesim-lite`](https://github.com/oist-ncbc/spykesim-lite), a collection of scripts that perform edit similarity calculation between two time series of multi-neuron spiking activity. In particular, `graphcheck` uses the `final_prof_dict_{suffix}.npz` dictionary file, which contains profile information.

### Installing `graphcheck`

Install using:

```sh
pip install -e .
```

This command will install `graphcheck` as a local library in your Python environment.

### Before running any notebooks

Edit `scripts/run_all.py` to set `path_data_root` and `path_prof_root` as the path to the raw data and to the profile analysis output obtained with `spykesim-lite`, respectively, and run the script:

```sh
python scripts/run_all.py
```

Also specify `path_data_root` in `scripts/movement_classes.py` and run the script to obtain trial statistics using the lever and event data files.

```sh
python scripts/movement_classes.py
```

Results of both scripts will be exported into the automatically created folder `results/`. For `run_all.py`, the output is indexed by date.

### Obtaining the figures

Main figures can be generated by running the notebooks below.

- `scripts/figure2_upload.ipynb`
- `scripts/figure3_upload.ipynb`
- `scripts/figure4_upload.ipynb`
- `scripts/figure5_upload.ipynb`

Supplementary figures can be obtained by changing the exponential gap penalty parameter `alpha`. For provenance, we provide the supplementary results in the files below.

- `scripts/supp_figure1_upload.ipynb`
- `scripts/supp_figure2_upload.ipynb`
- `scripts/supp_figure3_upload.ipynb`
- `scripts/supp_figure4_upload.ipynb`

*Note: statistical tests were explored using an automated heuristic based on sample normality and variance diagnostics but were then set manually. They may not match the reported values if changed.*
